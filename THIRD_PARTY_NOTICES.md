|---|---|---|
| Noto Sans, Noto Serif | © The Noto Project Authors | OFL-1.1 |
| Noto Sans Devanagari, Noto Serif Devanagari | © The Noto Project Authors | OFL-1.1 |

The OFL requires that the font files keep their licence and that any derivative
font be renamed. `fetch_fonts.py` merges per-script subsets of the same family
(for example Devanagari + Latin) into one file for embedding. That merged file
is a derivative work: it is renamed in its `name` table (`LayoutLoom:<family>`
in the unique-ID field) and is used only for PDF embedding, never redistributed
as a font product.
